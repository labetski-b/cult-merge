# Дефициты по типам геймплея и способы их решения

> Структура: Геймплей → Дефицит → Чем решается (Ad / IAP / Gems)
> Gems (hard_spend) атрибутированы к конечному дефициту, а не как отдельная категория

---

## TYCOON

### Ресурсы

Золото, материалы, производственные ресурсы tycoon-режима.


| Канал    | Placement / Product   | Что даёт                        |
| -------- | --------------------- | ------------------------------- |
| **Ad**   | `offline`             | x2 оффлайн-ресурсов             |
| **Ad**   | `offline_x3`          | x3 оффлайн-ресурсов             |
| **Ad**   | `x2_speed`            | x2 скорость производства        |
| **Ad**   | `x2_prod`             | x2 объём производства           |
| **Ad**   | `plus_adepts`         | Доп. культисты                  |
| **Ad**   | `context_offer`       | Контекстный буст (+ eyes)       |
| **IAP**  | `x2.tycoon.resources` | x2 tycoon-ресурсов на время     |
| **IAP**  | `4.hours.offline`     | +4ч оффлайн-ресурсов            |
| **Gems** | `time_machine`        | Ресурсы за N минут вперёд       |
| **Gems** | `offer_x2_speed`      | = ad x2_speed за кристаллы      |
| **Gems** | `offer_x2_prod`       | = ad x2_prod за кристаллы       |
| **Gems** | `offer_plus_adepts`   | = ad plus_adepts за кристаллы   |
| **Gems** | `context_offer`       | = ad context_offer за кристаллы |
| **Gems** | `context_offer_x2`    | x2 контекстный буст             |
| **Gems** | `raid_x2`             | x2 добыча при рейде на игрока   |


### Eyes

Глаза — зарабатываются в merge (кормление кракена), тратятся в tycoon на апгрейды.


| Канал    | Placement / Product  | Что даёт              |
| -------- | -------------------- | --------------------- |
| **Ad**   | `merge_reward_x2`    | x2 глаза за кормление |
| **IAP**  | `x2.merge.resources` | x2 множитель на eyes  |
| **Gems** | `merge_feed_x3`      | x3 глаза за кормление |


### Время

Таймеры постройки и апгрейда модулей в tycoon.


| Канал    | Placement / Product    | Что даёт              |
| -------- | ---------------------- | --------------------- |
| **Ad**   | —                      | **НЕТ**               |
| **IAP**  | —                      | **НЕТ**               |
| **Gems** | `force_upgrade_button` | Скип апгрейда модуля  |
| **Gems** | `force_build_button`   | Скип постройки модуля |

### Gems (источники хард-валюты)

Гемы — не дефицит сами по себе, а промежуточная валюта. Попадают в дефициты выше через hard_spend.


| Канал   | Placement / Product       | Что даёт        |
| ------- | ------------------------- | --------------- |
| **Ad**  | `dailyReward`             | Ежедневные гемы |
| **IAP** | `crystal.new.`* (6 паков) | Покупка гемов   |
| **IAP** | `piggybank.`*             | Копилка гемов   |
