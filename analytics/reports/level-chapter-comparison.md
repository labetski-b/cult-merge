## Ключевые выводы

### 1. Симуляция СИЛЬНО отстаёт в chapter progression

Начиная с chapter 8, симуляция показывает значительно более медленную прогрессию по главам относительно merge level. К chapter 17 разрыв достигает **~22 уровня**.

### 2. Точка расхождения — chapter 5 (level 8)

До chapter 5 симуляция и реальность совпадают (±1 level). После — расхождение нарастает линейно.

### 3. Возможные причины

| Причина | Объяснение |
|---------|------------|
| **Idle-ресурсы** | Реальные игроки получают ресурсы из idle-части игры (адепты на островах, алтарь, здания), которые дают eyes. Симуляция моделирует только merge-борд. |
| **Реклама за ресурсы** | Ad_watchers получают бонусные ресурсы/множители за просмотр рекламы, ускоряя chapter progression. |
| **Дневные награды** | `daily_reward_*` события дают ресурсы, не моделируемые в симуляции. |
| **Квесты idle-части** | `quest_rewarded`, `mission_complete` — idle-квесты дают eyes/ресурсы параллельно merge progression. |
| **Meat drop неточность** | Формула `calculateMeatDrop` может не учитывать бустеры и бонусы реальной игры. |

### 4. Chapter 18 — только у реальных игроков

Симуляция застревает на chapter 17 (cap в `chapters_data_analytics.json` — eyes end = 3,390,000). Реальные игроки достигают chapter 18 начиная с level 43, что означает наличие дополнительных источников eyes за пределами модели.

## Запросы

### Реальные данные (ClickHouse)
```sql
SELECT
    toUInt32(up_merge_level) AS merge_level,
    quantile(0.5)(up_chapter) AS median_chapter,
    quantile(0.25)(up_chapter) AS p25_chapter,
    quantile(0.75)(up_chapter) AS p75_chapter,
    uniq(uuid) AS users
FROM wazzitude.events1268
WHERE event_name = 'merge_level_up'
  AND install_date BETWEEN '2026-01-13' AND '2026-02-13'
  AND is_test = 0
  AND up_merge_level > 0
  AND uuid GLOBAL IN (
      SELECT uuid FROM wazzitude.events1268
      WHERE event_name = 'af_rewarded'
        AND install_date BETWEEN '2026-01-13' AND '2026-02-13'
        AND is_test = 0
  )
GROUP BY merge_level
ORDER BY merge_level
```

### Симуляция
```bash
# Запуск с записью level→chapter маппинга
npx tsx --tsconfig tsconfig.app.json scripts/sim-level-chapter.ts
```
