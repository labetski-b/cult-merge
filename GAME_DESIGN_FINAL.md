# CULT.MERGE - Финальная Game Design Document

## Обзор проекта
Веб-клон merge-игры из Unity для тестирования новых механик и баланса.

**Цель**: Быстрая итерация по балансу и механикам без необходимости билдить Unity-проект.

---

## Основные механики

### 1. Kraken (Главный персонаж)

**Роль**: Центральное существо, которое выдает заказы и прокачивается.

**Функции:**
- Выдает заказы на существ определенного типа и уровня
- При выполнении заказа дает награды: EXP и Eyes
- Повышает уровень при накоплении EXP
- Уровень Kraken влияет на размер игровой сетки

**Система уровней:**
- **Максимум**: 50+ уровней
- **Подуровни**: Каждый уровень имеет STEP 0, 1, 2
- **EXP**: Каждый шаг требует определенное количество опыта
- **Награды**: За достижение шагов даются сундуки (Res_Box)

**Размер игровой сетки:**

| Kraken Level | Grid Size | Total Cells |
|--------------|-----------|-------------|
| 1-4          | 2x4       | 8           |
| 5-6          | 3x4       | 12          |
| 7-11         | 4x4       | 16          |
| 12-19        | 5x4       | 20          |
| 20+          | 6x4       | 24          |

### 2. Система заказов (Tasks)

**Два типа заказов:**

1. **Mandatory Tasks (обязательные)**
   - Выполняются строго по порядку из `tasks.json`
   - Уникальны для каждого уровня Kraken
   - Нельзя пропустить или отказаться
   - `resMultiplier = 2` (x2 глаза)

2. **Auto Tasks (автогенерируемые)**
   - Запускаются сразу после окончания всех обязательных заданий уровня
   - Генерируются бесконечно, одно за другим
   - `resMultiplier = 1` (стандартная награда)

**Структура задачи:**
```
Task {
  id: "mandatory_task_lvl_2_1" | "auto_<timestamp>_<rand>"
  creatures: [{ type, level, count }]
  expMultiplier: 0
  resMultiplier: 2 (mandatory) | 1 (auto)
}
```

**Примеры обязательных заказов:**

**Level 2 (7 обязательных):**
1. 1x Creature1 LVL 2 → x2
2. 5x Creature1 LVL 1 → x2
3. 1x Creature1 LVL 3 → x2
4. 3x Creature1 LVL 2 → x2
5. 1x Creature1 LVL 4 → x2
6. 3x Creature1 LVL 3 → x2
7. 1x Creature1 LVL 4 → x2

**Level 3 (9 обязательных):**
- Первое появление Creature2 (вторая линейка)
- Требует существ до LVL 5

---

#### Автогенерация заданий

**Условие:** нет активной мандаторной задачи для текущего уровня (все выполнены или их нет вообще). Если нет ни mandatory, ни auto-задачи — авто-задание генерируется автоматически при отображении панели задач (lazy).

---

**Шаг 0 — Задание на существо с поля (10%)**

Если на поле есть хотя бы одно существо уровня ≥ 5:
- С вероятностью **50%** — выбираем случайное такое существо и генерируем задание на **1 штуку** его типа и уровня (уровень ограничивается `field_level_cap`). Алгоритм завершается.
- С вероятностью **50%** — продолжаем обычный алгоритм (шаги 1–8)

---

**Шаг 1 — Подсчёт потенциальных рун**

Суммируем все доступные руны:
- `resources.rune1` и `resources.rune2`
- Руны-сущности (`RuneEntity`) на поле → переводим через `runeRedemptionValue()`
- Мешки (`BoxEntity`) на поле → суммируем значения всех их `contents[]` через `runeRedemptionValue()` **без учёта мерджа**

**Шаг 2 — Сбор генераторов и виртуальный мердж**

1. Собираем все генераторы на поле, группируя по `generatorId` → массив уровней для каждого типа
2. Виртуальная покупка генераторов L1 — **от дорогого к дешёвому**, с вычетом из бюджета рун (Шаг 1). Генератор доступен только если `kraken.level ≥ krakenRequired`:

| Generator | purchaseCost | krakenRequired |
|-----------|-------------|----------------|
| Gen1      | 5 Rune1     | 1              |
| Gen2      | 5 Rune2     | 4              |
| Gen4      | 20 Rune2    | 10             |

Порядок проверки: Gen4 (20) → Gen2 (5) → Gen1 (5). После каждой покупки стоимость вычитается из бюджета соответствующей руны.
3. **Виртуальный мердж**: для каждой группы симулируем попарное объединение — пока есть 2+ генератора одного уровня, объединяем в level+1 (максимум 5). Пример: `[L1, L1, L1]` → `[L2, L1]`

**Шаг 3 — Потенциальный пул существ**

Для каждого генератора **после виртуального мерджа** (Шаг 2):
```
для каждого output в level.outputs:
  potentialCount[creatureType][level] += numCreatures × probability
```
Итог: словарь `{ creatureType → { level → count } }`.

> ⚠️ Виртуальный мердж учитывает покупку: если на поле Gen1 L1 и хватает рун на ещё один Gen1 → считаем как Gen1 L2 (а не два отдельных L1).

**Шаг 4 — Правило 90%**

Если в пуле доступно более 1 линейки:
- с вероятностью **90%** — исключаем линейку предыдущего задания из кандидатов
- с вероятностью **10%** — оставляем все линейки

*Если после исключения остаётся 0 линеек — возвращаем все.*

**Шаг 5 — Выбор линейки**

Ранжируем доступные линейки от старшей к младшей (по номеру генератора убывающе: Gen4 > Gen2 > Gen1; внутри генератора — по номеру существа убывающе).

Выбираем линейку с весами:

| Место | Линейка | Вес |
|-------|---------|-----|
| 1-е | Самая старшая | 70% |
| 2-е | Вторая | 20% |
| 3-е | Третья | 7% |
| 4-е | Четвёртая | 3% |
| 5-е и далее | — | игнорируются |

*Если линеек меньше 4 — веса нормализуются на имеющиеся.*

**Шаг 6 — Count**

Случайное число от **1 до 4**.

**Шаг 7 — max_lvl**

Из пула существ выбранной линейки (реальные на поле + потенциальные из спавнеров):
1. Переводим все существа в «L1-эквиваленты»: существо уровня L = `2^(L-1)` единиц L1
2. Суммируем всё → `totalL1`
3. `max_lvl = floor(log2(totalL1)) + 1`, ограничено `maxLevel` существа

**Шаг 7.5 — Ограничение по размеру поля**

Уровень существа не может превышать количество доступных клеток:

```
grid_cells         = rows × cols  (текущий размер по уровню Kraken)
generator_footprint = кол-во уникальных generatorId на поле
                     (все генераторы одной линейки — сколько бы их ни было —
                      = 1 клетка, т.к. линейка сводится к 1 через мердж)
available_cells    = grid_cells - generator_footprint
field_level_cap    = available_cells
```

| Grid | Генераторы | available_cells | cap |
|------|-----------|----------------|-----|
| 2×4=8 | 1 (любой тип) | 7 | Lv 7 |
| 2×4=8 | 2 одной линейки | 7 | Lv 7 |
| 2×4=8 | 2 разных линеек | 6 | Lv 6 |
| 3×4=12 | 1 генератор | 11 | Lv 11 |
| 4×4=16 | 2 разных линеек | 14 | Lv 14 |

**Шаг 8 — required_level**

Верхняя граница диапазона — динамическая, растёт с количеством выполненных автозаданий на эту линейку:

```
lineCompletions = autoTaskLineCompletions[creatureType] ?? 0
upper = min(max_lvl - 1 + floor(lineCompletions / 3), max_lvl + 4)
```

| Выполнено квестов на линейку | upper |
|------------------------------|-------|
| 0 | max_lvl - 1 |
| 3 | max_lvl |
| 6 | max_lvl + 1 |
| 9 | max_lvl + 2 |
| 12 | max_lvl + 3 |
| 15+ | max_lvl + 4 (cap) |

Базовое значение: `rand(max_lvl - 3, upper)` (включительно, равномерно).

Корректировка по count:
- count == 1 → без изменений
- count == 2 → `-1`
- count == 3 → `-2`
- count == 4 → `-2`

Итог: `clamp(required_level, 1, min(creature.maxLevel, field_level_cap))`.

> Счётчик `autoTaskLineCompletions` хранится в `GameSnapshot` и инкрементируется при завершении каждого автозадания для соответствующей линейки.

**Ограничения:**
- Два подряд одинаковых задания (`type + level`) невозможны — при совпадении задание перегенерируется целиком (повтор шагов 4–8, до 10 попыток)

**Награды:**
- EXP = сумма EXP всех существ (expMultiplier = 0, т.е. стандартный)
- Eyes = сумма Eyes всех существ × resMultiplier (= 1)

### 3. Merge механика

**Правило**: 2 одинаковых предмета → 1 предмет следующего уровня

**Что можно мерджить:**
- Существа (Creatures)
- Генераторы (Generators)
- Руны (Runes)

**Ограничения:**
- Максимальный уровень существ: 9
- Максимальный уровень генераторов: 5
- Максимальный уровень рун: 3

**Механика:**
1. Перетаскиваешь один объект на другой (drag-and-drop)
2. Если тип и уровень совпадают → мердж происходит
3. Новый объект появляется на месте цели
4. Старые объекты удаляются

### 4. Генераторы

**Типы генераторов:**

| ID         | Название       | Стоимость покупки | Линейки              | Тип             |
|------------|----------------|-------------------|----------------------|-----------------|
| 1          | Generator 1    | 5 Rune1           | Creature1, Creature2 | Зарядный        |
| 2          | Generator 2    | 5 Rune2           | Creature3, Creature4 | Зарядный        |
| FlowerPot  | FlowerPot      | 20 Rune1          | Creature5, Creature6 | Таймерный (§4.1)|
| 4          | Generator 4    | 20 Rune2          | Creature7, Creature8 | Зарядный        |

**Механика работы (Gen 1, 2, 4):**

1. **Покупка**: За руны в магазине (только уровень 1). Генератор создаётся **уже заряженным**
2. **Размещение**: На свободную клетку сетки
3. **Производство**: Генератор выбрасывает NUM существ на сетку
4. **Зарядка**: Когда пуст → платишь мясом → генератор заряжается
5. **Повтор**: Производство → зарядка → ...

**⚠️ ВАЖНО**: Генераторы всегда создаются заряженными — как при покупке, так и при мердже (апгрейде). Игрок может сразу тапнуть и получить существ, без предварительной оплаты мясом.

**Стоимость зарядки (мясо):**

| Генератор | LVL 1 | LVL 2 | LVL 3 | LVL 4 | LVL 5 |
|-----------|-------|-------|-------|-------|-------|
| Gen 1     | 1     | 1     | 2     | 5     | 10    |
| Gen 2     | 6     | 7     | 9     | 10    | 15    |
| Gen 4     | 12    | 14    | 16    | 18    | 20    |

**Производство существ:**

| Gen Level | NUM | CR1-1 | CR1-2 | CR2-1 | CR2-2 |
|-----------|-----|-------|-------|-------|-------|
| 1         | 15  | 100%  | 0%    | 0%    | 0%    |
| 2         | 20  | 54%   | 36%   | 10%   | 0%    |
| 3         | 25  | 42%   | 28%   | 18%   | 12%   |
| 4         | 30  | 20%   | 20%   | 30%   | 30%   |
| 5         | 40  | 4%    | 6%    | 36%   | 54%   |

*Генераторы 2 и 4 имеют идентичные таблицы*

**Обозначения:**
- CR1 = Creature линейка 1 (базовая)
- CR2 = Creature линейка 2 (улучшенная)
- CR1-1 = Creature линейки 1, уровень 1
- CR1-2 = Creature линейки 1, уровень 2

**⚠️ ВАЖНО**: Генератор выдает только существ уровней 1 и 2. Остальные уровни (3-9) получаются мерджем!

**Гарантия второй линейки**: При создании генератора (покупка, мердж) первое существо в заряде гарантированно из второй линейки (CR2), уровень 1. Например, Gen1 L2 всегда первым выдаст Creature2 L1. Это срабатывает **один раз за жизнь генератора** — при перезарядке мясом все существа роллятся по обычным шансам. Если вторая линейка недоступна на уровне генератора (Gen L1) — обычный ролл.

**Апгрейд генераторов:**
- Только через мердж: 2 генератора одного уровня → 1 генератор +1 уровня
- Пример: Gen1-1 + Gen1-1 = Gen1-2
- Результат мерджа создаётся **уже заряженным**
- При апгрейде увеличивается шанс второй линейки (CR2)

### 4.1 Цветочный горшок (FlowerPot)

**Тип**: Пассивный спавнер на реальном времени
**Линейки**: Creature5, Creature6

#### Отличия от обычных генераторов

| Параметр        | Gen 1 / 2 / 4      | FlowerPot            |
|-----------------|--------------------|----------------------|
| Топливо         | Мясо (meat)        | Нет                  |
| Вместимость     | Задана по уровню   | Нет                  |
| Производство    | Ручной тап         | Автоматически        |
| Интервал        | По запросу         | 30 минут             |
| Оффлайн-прогресс| —                  | Да, таймер в фоне    |

#### Покупка и уровни

- **Покупка**: В магазине за **20 Rune1** (только 1-й уровень)
- **Уровней**: 5
- **Апгрейд**: Мердж 2 горшка одного уровня → 1 горшок +1 уровня

#### Механика работы

1. Горшок размещается на свободную клетку сетки
2. Каждые **30 минут** горшок пытается заспавнить 1 существо
3. Существо появляется на случайной свободной клетке из **8 соседних** (включая диагональ)
4. Если все 8 соседних клеток заняты → существо **не появляется**, таймер сбрасывается и начинается заново
5. Таймер считается в реальном времени, в том числе при закрытом приложении (оффлайн-прогресс)
6. Оффлайн накапливаются все циклы: например, 2 часа = 4 спавна. При возврате они применяются один за другим, пока есть свободные соседние клетки
7. У каждого горшка на поле — **свой независимый таймер**

#### Таблица производства

| LVL | Creature5 | Creature6 | CR5-L1 | CR5-L2 | CR6-L1 | CR6-L2 |
|-----|-----------|-----------|--------|--------|--------|--------|
| 1   | 100%      | 0%        | 100%   | 0%     | —      | —      |
| 2   | 90%       | 10%       | 60%    | 40%    | 100%   | 0%     |
| 3   | 70%       | 30%       | 60%    | 40%    | 60%    | 40%    |
| 4   | 40%       | 60%       | 50%    | 50%    | 50%    | 50%    |
| 5   | 10%       | 90%       | 40%    | 60%    | 40%    | 60%    |

**Обозначения:**
- CR5-L1 = Creature5 уровень 1
- CR5-L2 = Creature5 уровень 2

#### Технические заметки

- Entity kind: `'flowerpot'` (отдельный тип, не переиспользует `'generator'`)
- Поле `lastSpawnTimestamp: number` хранится прямо в сущности горшка (epoch ms)
- При загрузке игры: вычислить `Math.floor((Date.now() - lastSpawnTimestamp) / 1_800_000)` → применить столько спавнов подряд, сколько вместят свободные соседние клетки
- Поиск соседних клеток: Chebyshev distance = 1 (8-направленный)
- Случайная соседняя клетка выбирается через seeded RNG

### 5. Существа (Creatures)

**8 линеек существ:**

| Линейка   | Генератор | Тип линейки |
|-----------|-----------|-------------|
| Creature1 | Gen 1     | Линейка 1   |
| Creature2 | Gen 1     | Линейка 2   |
| Creature3 | Gen 2     | Линейка 1   |
| Creature4 | Gen 2     | Линейка 2   |
| Creature5 | Gen 3     | Линейка 1   |
| Creature6 | Gen 3     | Линейка 2   |
| Creature7 | Gen 4     | Линейка 1   |
| Creature8 | Gen 4     | Линейка 2   |

**Уровни:**
- Максимум: 9 уровней (может быть меньше для конкретной линейки)
- Получение: Уровни 1-2 из генераторов, 3-9 только через мердж

**Мердж:**
- Формула: 2x Creature LVL N → 1x Creature LVL (N+1)
- Пример: 2x Creature1 LVL 3 → 1x Creature1 LVL 4

**Награды за существ (при кормлении Kraken):**

Базовая линейка (Creature1):

| LVL | EXP | EYES |
|-----|-----|------|
| 1   | 1   | 2    |
| 2   | 2   | 4    |
| 3   | 4   | 8    |
| 4   | 8   | 16   |
| 5   | 16  | 32   |
| 6   | 32  | 64   |
| 7   | 64  | 128  |
| 8   | 128 | 256  |
| 9   | 256 | 512  |

**Формулы:**
- EXP(LVL) = 2^(LVL-1)
- EYES(LVL) = 2^LVL

**Для других линеек:**
- **EXP**: всегда x2 от Creature1
  - Любая линейка (2-8) дает двойной опыт
  - Creature2 LVL 5 = 32 EXP (16 × 2)

- **EYES**: x2 за каждую следующую линейку
  - Creature1 (Gen 1, линейка 1): базовые значения
  - Creature2 (Gen 1, линейка 2): x2 от Creature1
  - Creature3 (Gen 2, линейка 1): x2 от Creature2 = x4 от Creature1
  - Creature4 (Gen 2, линейка 2): x2 от Creature3 = x8 от Creature1
  - И так далее...

**Пример для LVL 5:**
- Creature1: 16 EXP, 32 Eyes
- Creature2: 32 EXP, 64 Eyes
- Creature3: 32 EXP, 128 Eyes
- Creature4: 32 EXP, 256 Eyes
- Creature5: 32 EXP, 512 Eyes
- Creature6: 32 EXP, 1024 Eyes
- Creature7: 32 EXP, 2048 Eyes
- Creature8: 32 EXP, 4096 Eyes

### 6. Хищники (Predators)

**Обзор:**
Хищники — существа, периодически появляющиеся на поле мерджа. Игрок должен накормить хищника, бросая на него существ. Накормленный хищник исчезает и награждает сундуком с карточками менеджеров.

**Условия появления:**

Хищник каждого типа появляется, когда выполнены **оба** условия одновременно:
1. Уровень Kraken ≥ `krakenRequiredLevel` (значение из баланса)
2. Игрок совершил ≥ `mergeCount` мерджей **с момента последнего появления хищника этого типа** (или с начала игры)

На поле может одновременно находиться **несколько хищников** разных типов. Счётчик мерджей у каждого типа хищника независимый.

**Баланс хищников (`src/data/predators.json`):**

| ID          | RequiredEXP | Preferred Creature | Kraken Level | Merge Count |
|-------------|-------------|-------------------|--------------|-------------|
| Predator_1  | 100         | Creature1         | 6            | 8           |
| Predator_2  | 100         | Creature2         | 6            | 230         |
| Predator_3  | 100         | Creature3         | 6            | 230         |
| Predator_4  | 100         | Creature4         | 10           | 230         |
| Predator_5  | 100         | Creature5         | 14           | 230         |
| Predator_6  | 100         | Creature6         | 15           | 230         |
| Predator_7  | 100         | Creature7         | 19           | 230         |
| Predator_8  | 100         | Creature8         | 22           | 230         |

*Predator_1 — обучающий хищник, появляется уже на 8-м мердже.*

**Механика кормления:**
- Игрок перетаскивает существо на хищника (аналогично Kraken)
- Существо типа `preferredCreatureType` даёт **×2 EXP** (остальные ×1)
- EXP берётся из `baseExp` существа данного уровня (с учётом `expMultiplier`)
- Когда накоплено ≥ `requiredExp` — хищник насыщен и исчезает с поля

**Размещение:**
- Хищник занимает **1 случайную свободную клетку** грида при появлении

**Награда за насыщение:**
- Исчезает с грида и выдаёт **сундук с карточками менеджеров**
- Из 7 менеджеров случайно выбирается **5 карточек** (дубликаты допустимы)
- Карточки добавляются в коллекцию игрока

**Менеджеры:**
- 7 уникальных менеджеров (draft balance: Manager_1 ... Manager_7)
- Механики менеджеров — post-MVP, пока только коллекционирование
- Баланс: `src/data/managers.json`

**UI элементы:**

1. **Прогресс-бар на хищнике** — отображает текущий EXP / requiredExp
2. **Панель прогресса мерджей (HUD)** — для каждого типа хищников:
   - Если Kraken Level < `krakenRequiredLevel` → **«Откроется на уровне X»** (заблокировано)
   - Если по уровню условие выполнено → прогресс-бар мерджей: «X / mergeCount»
3. **Экран коллекции менеджеров** — 7 ячеек, отображает собранные карточки

## Ресурсы

### 1. Мясо (Meat) - оранжевая иконка

**Назначение**: Зарядка генераторов

**Получение**:
- В MVP: Временная кнопка "Get Meat" (чит для тестирования)
- В будущем: Заработок в другом геймплее

**Стартовое количество**: 5 мясо

### 2. Глаза (Eyes) - желтая иконка

**Назначение**: Валюта прогресса (в MVP не используется для покупок)

**Получение**: Награда за выполнение заказов Kraken

**Формула**:
```
Reward Eyes = Sum(Creature Eyes) × Task Res Multiplier
```

### 3. Руны (Runes)

**Два типа рун**: Rune1, Rune2

**Система уровней:**

| Тип   | Уровень | Мердж            | Награда при скармливании |
|-------|---------|------------------|--------------------------|
| Rune1 | 1       | -                | 2 валюты Rune1           |
| Rune1 | 2       | 2x LVL1 → 1x LVL2| 5 валюты Rune1           |
| Rune1 | 3       | 2x LVL2 → 1x LVL3| 12 валюты Rune1          |
| Rune2 | 1       | -                | 2 валюты Rune2           |
| Rune2 | 2       | 2x LVL1 → 1x LVL2| 5 валюты Rune2           |
| Rune2 | 3       | 2x LVL2 → 1x LVL3| 12 валюты Rune2          |

**Механика:**
1. Получаешь предметы рун из сундуков (Res_Box)
2. Мерджишь руны как существ (2 → 1)
3. Скармливаешь руну Kraken → получаешь валюту рун
4. Покупаешь генераторы за валюту рун

**Назначение валюты:**
- **Rune1**: Покупка генераторов 1 и 3
- **Rune2**: Покупка генераторов 2 и 4

### 4. Hard-валюта (Гемы) - розовая иконка

**Статус**: Пока не важна для MVP

**Получение**: Иногда выпадает из сундуков

## Прогрессия Kraken

**Структура уровней:**
- Уровни: 1-50+
- Каждый уровень имеет подуровни (STEP): 0, 1, 2
- Каждый шаг требует EXP
- За шаги даются награды (сундуки)

**Примеры требований EXP:**

| Level | Step | EXP Required | Reward     |
|-------|------|--------------|------------|
| 1     | 0    | 0            | Egg        |
| 2     | 0    | 15           | -          |
| 3     | 0    | 40           | Res_Box #1 |
| 4     | 0    | 120          | -          |
| 4     | 1    | 85           | Res_Box #2 |
| 5     | 0    | 170          | -          |
| 5     | 1    | 250          | Res_Box #2 |
| ...   | ...  | ...          | ...        |

**Прогрессия:**
- Начальные уровни: 15-170 EXP
- Средние уровни: 500-2000 EXP
- Поздние уровни: ~90 EXP за шаг (стабилизация)

## Геймплейный луп

1. **Старт игры**
   - Получаешь: 5 мясо, генератор 1-1 на поле
   - Сетка: 2x4 (8 клеток)
   - Kraken: LVL 1-0

2. **Производство существ**
   - Генератор уже заряжен — тапаешь и получаешь 15x Creature1 LVL 1 на сетку
   - После опустошения заряжаешь мясом (стоит 1 мясо)

3. **Мердж существ**
   - Объединяешь 2x Creature1 LVL 1 → 1x Creature1 LVL 2
   - Продолжаешь мерджить до нужного уровня

4. **Выполнение заказа**
   - Kraken требует: 1x Creature1 LVL 2
   - Перетаскиваешь существо на Kraken
   - Получаешь: EXP (2 × 2 = 4) и Eyes (4 × 2 = 8)

5. **Прокачка Kraken**
   - Накапливаешь EXP → повышаешь уровень
   - Получаешь сундук (Res_Box)
   - Открываешь сундук → получаешь руны

6. **Система рун**
   - Мерджишь руны до нужного уровня
   - Скармливаешь руну Kraken → получаешь валюту рун
   - Накапливаешь валюту

7. **Покупка генераторов**
   - Покупаешь новый генератор за 5 Rune1 (создаётся заряженным)
   - Размещаешь на сетку → сразу можно производить существ
   - Можешь мерджить генераторы для апгрейда

8. **Расширение**
   - Сетка растет с уровнем Kraken
   - Появляются новые линейки существ
   - Сложность заказов увеличивается

9. **Повтор цикла**
   - Продолжаешь мерджить, выполнять заказы, прокачиваться
