**Выводы:**

1. **fieldL1 удешевляет квест**: C1 L5 на поле = +16 L1-эквивалентов → totalL1 = 128.2 вместо 112.2
2. **Фантомные апгрейды**: Gen1 L5 лучше для C2 (выше l1/meat 11.52 vs 9.00), Gen4 L3 поднимает C8, Gen2 L3 обходит Gen2 L4 для C3 (равный targetLv, но l1/m 4.90 > 3.60)
3. **Непрерывный расчёт** поднял некоторые targetLevel: C7 Lv6→Lv7, C9 Lv5→Lv6, C4 Lv5→Lv6 (дробные charges дают больше spawnL1)
4. **Диапазон Lv2–Lv8**, secondary creatures (C8, C10) системно слабее; D4 заметно щедрее D3
5. **Weighted selection** сильно смещает вероятность к новейшим линейкам: C9+C10 ~41% vs C1+C2 ~8%
