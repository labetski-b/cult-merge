**Выводы:**

1. **fieldL1 удешевляет квест**: C1 L5 на поле = +16 L1-эквивалентов → totalL1 = 124 вместо 108
2. **Фантомные апгрейды**: Gen1 L5 лучше для C2 (secondary→primary, равный targetLv но меньше charges), Gen4 L3 поднимает C8, Gen2 L3 обходит Gen2 L4 для C3
3. **Диапазон Lv2–Lv8**, secondary creatures (C8, C10) системно слабее; D4 заметно щедрее D3 (18.7 vs 6.0 meat)
4. **Weighted selection** сильно смещает вероятность к новейшим линейкам: C9+C10 ~41% vs C1+C2 ~8%
