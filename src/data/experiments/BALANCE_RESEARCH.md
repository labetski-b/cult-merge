# Balance Research: New Generators Experiment

Комплексное исследование баланса для добавления генераторов 5, 6, 7, 8.
Состоит из нескольких частей, каждая фиксирует одну "опорную точку" баланса.

## Общая цель

Сбалансировать игру так, чтобы:
- Kraken L50 и последняя глава (Ch17) достигались примерно одновременно
- Прогрессия ощущалась быстрой в начале и плавно замедлялась
- Экономика поддерживала 7 генераторов (Gen1, Gen2, Gen4-Gen8)

## Часть 1: Eye-Chapter Balance ✅

**Папка**: `1.eye-chapter-balance/`
**Дата**: 2026-02-27
**Статус**: применено к production

### Проблема

Текущая кривая глав:
- Ch17 (440K) < Ch16 (478K) — нарушена монотонность
- Все главы заканчиваются на Kraken ~L40, dead zone L40-L49
- Ratios хаотичные (0.92x — 9.97x)

### Решение

Перебалансировка `merge_resource` для Ch2-Ch17. Формула:
```
ratio(i) = 1.9395 - i × (1.9395 - 1.10) / 13,  i = 0..13 (Ch4-Ch17)
```

## Часть 2: Meat-to-Eyes Economy ✅

**Папка**: `2.meat-to-eyes-economy/`
**Дата**: 2026-03-02
**Статус**: применено к production

### Проблема

Baseline efficiency (eyes/meat) имеет аномалии:
- Gen5 L2 spike +107% (cost ПАДАЕТ 8→7 при апгрейде)
- Gen6-8 L2 spikes +81% (cost L2 = cost L1, output ×1.81)
- Gen1 с реальным baseline (1,1,2,5,10): drops -37% на L4, -16% на L5

### Ограничения

1. **Dual-resource**: нельзя трогать eyesMult без expMultiplier (проверено: eyesMult 1→3 для Creature1 привёл к -66% levels)
2. **Session budget**: 7-10 зарядов суммарно за сессию (подтверждено: avg 8.49, 67% сессий = 7-8)
3. **Part 1 alignment**: Ch16=L49, Ch17=L54
4. **Три-way interaction**: нельзя одновременно менять Gen2 + Gen4 + Gen5 L1 (коллапс -89 levels)

### Решение (v5)

Только chargeCost. Паттерн **"step-up-then-plateau"** для Gen5-Gen8:
- L1: базовый cost (ниже baseline)
- L2: cost повышается (под ×1.81 скачок total output)
- L3-L5: cost FLAT на уровне L2

Gen1: 1,1,2,3,5 (фикс от реального baseline 1,1,2,5,10)
Gen2: baseline (3,4,5,5,8) — spike +58% оставлен (spike = reward, не вредит)
Gen4: реальный baseline (6,7,8,9,10) — уже монотонный

### Изменённые chargeCost

|-----|----------|-----------------|---|
| Gen1 | 1,1,2,5,10 | **1,1,2,3,5** | L4: -2, L5: -5 |
| Gen2 | 3,4,5,5,8 | 3,4,5,5,8 | без изменений |

| Gen6 | 12,12,14,15,17 | **11,14,14,14,14** | L1: -1, L2: +2, L4: -1, L5: -3 |
| Gen7 | 15,15,17,19,21 | **13,17,17,17,17** | L1: -2, L2: +2, L4: -2, L5: -4 |
| Gen8 | 17,17,19,20,22 | **15,19,19,19,19** | L1: -2, L2: +2, L4: -1, L5: -3 |

Total cost: 389 (baseline 397, -2%)

### Вывод

## Часть 3: Generator Unlock Pacing ✅

**Папка**: `3.generator-unlock-pacing/`
**Дата**: 2026-03-02
**Статус**: анализ завершён, изменений нет

### Проблема

Оптимальность krakenRequired для 7 генераторов. Анализ через метрику New Creatures Discovered.

### Результат анализа

- Все генераторы покупаются ровно на krakenRequired (шаг +5 уровней)
- Время между покупками растёт: 50m → 91m → 93m → 115m → 141m → 168m
- Early game (Lv1-18): 56 открытий за 37 сессий = 1.5/ses — отличный пейсинг
- Mid game (Lv18-33): 41 открытие за 88 сессий = 0.47/ses — приемлемо
- Late game (Lv33-50): 27 открытий за 168 сессий = 0.16/ses — замедление в 10×, но неизбежно после последнего генератора

### Вывод

Текущий пейсинг приемлем. Менять krakenRequired не будем.
