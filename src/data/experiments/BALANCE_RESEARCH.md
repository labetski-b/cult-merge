# Balance Research: New Generators Experiment

Комплексное исследование баланса для добавления генераторов 5, 6, 7, 8.
Состоит из нескольких частей, каждая фиксирует одну "опорную точку" баланса.

## Общая цель

Сбалансировать игру так, чтобы:
- Kraken L50 и последняя глава (Ch17) достигались примерно одновременно
- Прогрессия ощущалась быстрой в начале и плавно замедлялась
- Экономика поддерживала 7 генераторов (Gen1, Gen2, Gen4-Gen8)

---

## Часть 1: Eye-Chapter Balance ✅

**Папка**: `1.eye-chapter-balance/`
**Дата**: 2026-02-27
**Статус**: применено к production

### Проблема

Текущая кривая глав:
- Ch17 (440K) < Ch16 (478K) — нарушена монотонность
- Все главы заканчиваются на Kraken ~L40, dead zone L40-L49
- Ratios хаотичные (0.92x — 9.97x)

### Решение

Перебалансировка `merge_resource` для Ch2-Ch17. Формула:
```
ratio(i) = 1.9395 - i × (1.9395 - 1.10) / 13,  i = 0..13 (Ch4-Ch17)
```
