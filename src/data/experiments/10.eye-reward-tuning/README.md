## Формула награды в глазах

### Принцип

Награда за квест определяется **реальной стоимостью существ в мясе**, а не фиксированным множителем сложности. Это гарантирует справедливость: дорогое существо всегда даёт много глаз, независимо от позиции в цикле.

### Стоимость существа в мясе (из scoring table)

Scoring table при генерации квеста уже рассчитывает для каждого существа:

- `l1Spawns` — сколько L1-эквивалентов нужно заспаунить: `2^(level-1)`
- `l1PerMeat` — сколько L1-эквивалентов даёт 1 мясо (зависит от генератора и его уровня)

```
creatureMeatCost = l1Spawns / l1PerMeat
```

Пример: Creature3 Lv4 → нужно `2^3 = 8` L1-eq, генератор даёт 5 L1/meat → стоимость = 1.6 мяса.

### Стоимость квеста

```
questMeatCost = Σ(creatureMeatCost_i × count_i)
```

Для dual-quest — сумма по обеим частям.

### Награда

```
eyeReward = floor(questMeatCost × eyePerMeat[chapter])
```

`eyePerMeat[chapter]` — **единственный настраиваемый коэффициент** на чаптер. Конвертирует мясо в глаза.

### Калибровка eyePerMeat

Чтобы средний reward по циклу из 9 квестов = avgReward:

```
eyePerMeat[ch] = avgReward[ch] / avgQuestMeatCost[ch]
```

`avgQuestMeatCost` зависит от:

- Какие генераторы открыты (определяет l1PerMeat)
- Какие уровни существ достижимы (определяет l1Spawns)
- Бюджет мяса на квест (из difficultySacMap + meatDrop)

### Пример: Chapter 10 (avgReward = 1700)

Допустим средний questMeatCost по циклу ≈ 8.5 мяса.

```
eyePerMeat[10] = 1700 / 8.5 = 200
```

### Свойства формулы

1. **Справедливость**: дорогое существо на diff1 → высокая награда (не "копейки за Cr10 Lv5")
2. **Масштабируемость**: один коэффициент на чаптер, остальное — из scoring table
3. **Самокалибровка**: при открытии новых генераторов l1PerMeat меняется → стоимость пересчитывается автоматически
4. **Предсказуемость**: игрок видит закономерность — чем сложнее существо, тем больше глаз
