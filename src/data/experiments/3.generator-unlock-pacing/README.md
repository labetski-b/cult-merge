# Experiment: Generator Unlock Pacing (Part 3)

## Цель

Оптимизировать `krakenRequired` для генераторов, чтобы:
- Новые существа появлялись равномерно по ходу игры
- Не было длительных drought-ов (сессий без новых открытий)
- Временные промежутки между генераторами не росли экспоненциально

## Предыдущий эксперимент

В папке `gen-unlock-pacing/` лежит устаревший эксперимент (до Part 1 и Part 2). Ключевые находки оттуда:
- **Binding constraint** = не всегда `krakenRequired`, а рунная доступность (Gen2 нельзя купить раньше ~L8, даже с krakenRequired=1 — нет rune2)
- Снижение krakenRequired помогает только если сам krakenRequired является binding constraint
- Ранние уровни дают меньше рун → ранний анлок удлиняет промежуток до следующего генератора

## Анализ проблем

### 1. Время между генераторами растёт экспоненциально

Шаг по уровням = 5, но шаг по времени (минуты):
```
Gen1→Gen2: 50m
Gen2→Gen4: 91m (+82%)
Gen4→Gen5: 93m (+2%)
Gen5→Gen6: 115m (+24%)
Gen6→Gen7: 141m (+23%)
Gen7→Gen8: 168m (+19%)
```

Первый промежуток 50m, последний 168m — 3.4× разница. Из-за нелинейного роста EXP на уровень.

### 2. Content cliff на Lv34-50

После Gen8 (Lv33) до L50 все новые существа = только merge Lv5-7 старых линий. Это 27 открытий за ~168 сессий = 0.16/ses. Для сравнения, Lv1-18 = 56 открытий за 37 сессий = 1.5/ses. Замедление в ~10 раз.

### 3. Вторая линия (CrB) у поздних генераторов появляется слишком поздно

Gen7: CrB (Creature14) первый spawn на ses 122, через **31 сессий** после покупки Gen7 (ses 91). Это потому что CrB.1 имеет 10% шанс на L2, а Gen7 нужно сначала замерджить до L2.

### 4. Gen2 binding = rune2, не krakenRequired

Gen2 krakenRequired=7, но покупка на Lv8 — rune2 недоступен до L8. Снижение krakenRequired Gen2 не поможет (проверено в gen-unlock-pacing v1/v2).

## Возможные направления оптимизации

### A. Сжатие промежутков для поздних генераторов

Текущие krakenRequired с равным шагом 5:
```
Gen1=1, Gen2=7, Gen4=13, Gen5=18, Gen6=23, Gen7=28, Gen8=33
```

Вариант с уменьшающимся шагом (чтобы компенсировать рост времени на уровень):
```
Gen1=1, Gen2=7, Gen4=13, Gen5=17, Gen6=21, Gen7=25, Gen8=29
```

Но: может нарушить рунный баланс (Gen7 и Gen8 = binding по рунам, не по krakenReq).

### B. Добавление purchaseCost tier

Снижение purchaseCost для Gen7 (60→40 rune1) или Gen8 (60→40 rune2) чтобы реальная покупка приблизилась к krakenRequired.

### C. Content cliff Lv34-50

Замедление в 10× неизбежно после последнего генератора. Сжатие промежутков (вариант A) сместит cliff ближе к Lv30, но не устранит. Реальное решение — новые генераторы или механики, но это за рамками текущего эксперимента.
