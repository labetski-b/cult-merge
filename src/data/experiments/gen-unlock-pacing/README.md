# Experiment: gen-unlock-pacing

**Гипотеза:** Текущее расписание разблокировки генераторов создаёт аномальные паузы —
особенно в первые 30-90 минут, когда доступен только Gen1 (Creature1/2), а Gen2 и Gen4
приходят слишком поздно. Нужна равномерная кривая: быстро в начале, плавно замедляется.

**Ключевое открытие:** Binding constraint для покупки генератора — НЕ всегда `krakenRequired`,
а рунная доступность. Gen2 (5 rune2) нельзя купить раньше ~L8, даже с krakenRequired=1 —
просто нет rune2. Поэтому изменение `krakenRequired` работает только там, где оно само
является ограничителем, а не рунный баланс.

**Найденный баг и фикс:** `RealisticStrategy` использовала глобальный `BALANCE` вместо
balance из конфига движка. Это приводило к тому, что стратегия не могла купить Gen4 (думала,
что unlocked на L13), а engine уже давал квесты на Creature7 (L7 по expBalance) → полный стоп
симуляции на L10. Исправлено: `RealisticStrategy` теперь принимает инъектируемый balance
в конструктор; `run-experiment.ts` передаёт `expBalance` в стратегию эксперимента.

**Изменения `krakenRequired`:**

- Gen2 пришёл так же (~52 мин): rune2 всё ещё bottleneck до L8

- Gen6→Gen7: **160 мин** (хуже baseline!) — потому что Gen6 пришёл на L17 при низких ставках rune1

**Примечание про Gen2:** krakenRequired=5 не изменил реального времени, т.к. rune2 нет до L8.
Но система квестов уже с L5 добавляет Creature3 в пул через Pass A. Игрок видит квесты
на Creature3 раньше, даже если не может произвести их сразу.

**Примечание про Gen6→Gen7 (160 мин):** Это ХУЖЕ baseline (132 мин). Причина:
Gen6 теперь покупается на L17 (vs L23), ставки rune1 на L17-24 ниже, чем на L23-29.
Требование Gen7 (60 rune1) достигается медленнее при более раннем старте накопления.
→ Надо рассматривать отдельно (изменение purchaseCost Gen7 или rune1 emission rate).

## Ключевые инсайты

1. **krakenRequired только создаёт ворота, рунная доступность — второй ограничитель.**
   Снижение krakenRequired помогает только если сам krakenRequired был binding constraint.
   Если binding constraint = рунный баланс, изменение ничего не даёт (Gen2 at L5 ≡ L7).

2. **Ранние уровни дают меньше рун.** Bringing Gen6 to L17 means Gen7 starts rune1
   accumulation at L17 with lower rune income → gap to Gen7 actually LONGER (160 vs 132 min).

3. **Паузы в раннем геймплее улучшились драматично:**
   - Gen2→Gen4: 37 мин vs 86 мин (−57%) ✓
   - Gen4→Gen5: 49 мин vs 94 мин (−48%) ✓
   - Gen5→Gen6: 72 мин vs 116 мин (−38%) ✓

4. **Открытая проблема:** Gen6→Gen7 = 160 мин (хуже baseline). Для финального балансирования
   нужно либо снизить purchaseCost Gen7 (60→40 rune1), либо повысить rune1 emission на mid-уровнях.
