# Experiment: eye-chapter-balance

## Гипотеза

Текущая кривая chapter progression имеет три проблемы:
1. **Dead zone L33-L49**: игрок проходит все 16 глав к Kraken ~L40, оставшиеся 9+ уровней — без прогрессии по главам
2. **Нарушение монотонности**: Ch17 (440K) < Ch16 (478K) — последняя глава короче предпоследней
3. **Хаотичные ratios**: множитель между главами скачет от 0.92x до 9.97x без закономерности

**Цель**: перебалансировать `merge_resource` (eyes) для Ch2-Ch17 так, чтобы Ch17 заканчивалась на ≈Kraken L49-50, с гладкой убывающей кривой ratios.

### Формула кривой

Двухрежимная структура:
- **Ch2-Ch3**: туториальные якоря (без изменений)
- **Ch4-Ch17**: ratio линейно убывает от 1.94 до 1.10

```
ratio(i) = 1.9395 - i × (1.9395 - 1.10) / 13,  i = 0..13
```

Даёт серию ratios: 1.94, 1.87, 1.81, 1.75, 1.68, 1.61, 1.56, 1.49, 1.42, 1.36, 1.29, 1.23, 1.16, 1.10

## Компромиссы

1. **Ch6 вырос на +78%** — самое существенное изменение в "быстрых" главах. К L10 игрок уже имеет Gen2 и зарабатывает eyes быстрее, поэтому в реальном времени замедление умеренное.
