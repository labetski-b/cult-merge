## Image File Naming Convention

### Creatures
- Format: `{creature_name}_lvl{level}.png`
- Example: `spider_lvl1.png`, `imp_lvl3.png`

### Spawners
- Format: `{spawner_name}_lvl{level}.png`
- Example: `nest_lvl1.png`, `book_lvl2.png`
