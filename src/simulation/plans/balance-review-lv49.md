### 2.4. Кривая EXP: линейная проблема

Требования EXP растут **линейно** (+30/шаг, +90/уровень):
- Lv 8: 530/шаг = 1590 за уровень
- Lv 20: 890/шаг = 2670 за уровень
- Lv 33: 1280/шаг = 3840 за уровень
- Lv 49: 1760/шаг = 5280 за уровень (3.3× от Lv8)

Но EXP/tick **стагнирует** на ~15-17 после Lv25 (нет новых генераторов = мощность не растёт). Результат: каждый уровень всё медленнее:

| Диапазон | Ср. тиков/уровень |
|----------|:-:|
| Lv 8-13 | ~158 |
| Lv 23-28 | ~190 |
| Lv 33-40 | ~290 |
| Lv 40-49 | ~315 |

### 2.5. Монотонность наград

Начиная с уровня 20, **ВСЕ 90 наградных слотов** (Lv20-49) — это `res_box #7`. Абсолютная монотонность. 100% одинаковых наград на 30 уровнях подряд.

До Lv20 было разнообразие: box#1, box#2, box#4, box#6, grid, egg, mechanic.

### 2.6. Аномалия Post-49

После уровня 49 вступает `defaultStepExp = 500` с 1 шагом. Это приводит к **резкому ускорению в ~10×**:
- Lv 49: 338 тиков (5280 EXP, 3 шага)
- Lv 51: 28 тиков (500 EXP, 1 шаг)

Игрок за то же время, что проходил 1 уровень, теперь проходит 10+.

### 3.3. Доход рун по фазам

**Фаза 1 (Lv1-6)**: только rune1. Боксы 1 и 2 = **28 rune1, 0 rune2**. Полное отсутствие rune2.

### 3.4. Критические проблемы экономики

**A. Rune2 = 0 при разблокировке Gen2 (Lv7)**
- Уровни 1-6 дают ТОЛЬКО rune1
- Gen2 разблокируется на Lv7 и стоит rune2
- Игрок видит новый генератор, но не может его купить 1-2 степа

**B. Поздние генераторы недоступны для максимизации**
- Gen5-Gen8 покупаются всего по 4 копии за всю симуляцию (25% от макс)
- Для макс Gen7 (960 rune1) нужно ~83 уровня ЧИСТОГО дохода без других трат
- Это нереалистично в рамках 49 уровней

**C. Box#7 — 34% содержимого уходит в gems (Hard руны)**
- 23.8% Hard_1 + 10.2% Hard_2 = 34% слотов — gems
- Только 66% слотов дают руны (33% rune1, 33% rune2)
- Gems не имеют видимого применения — возможно мёртвый ресурс

**D. Профицит рун на Lv40-45 без sink'ов**
- r1=110, r2=75 — накапливаются без цели
- Между Lv38-44: 0 покупок генераторов
- Ресурсный sink недостаточен

### 6.1. QUICK WINS — только JSON, без кода

#### QW-1: Дать rune2 до разблокировки Gen2

**Файл**: `kraken_progression.json`

```
Было:  { "level": 6, "step": 1, ..., "reward": { "type": "res_box", "value": 2 } }
Стало: { "level": 6, "step": 1, ..., "reward": { "type": "res_box", "value": 6 } }
```
