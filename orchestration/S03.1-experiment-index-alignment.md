# S03.1: Experiment Index Alignment

## Цель

Закрыть единственный remaining finding после S03:

- `src/data/experiments/README.md` уже использует новый канонический словарь;
- но таблица экспериментов внизу все еще ссылается на старые folder names, которых больше нет или которые не являются актуальными entry points.

Нужно привести experiment index в соответствие с реальной структурой `src/data/experiments/`, не расползаясь в большой docs-cleanup.

## Контекст

После S03:

- glossary уже добавлен;
- базовые vocabulary boundaries уже введены;
- остался один точечный конфликт между новым словарем и старым индексом экспериментов.

Это чистый follow-up на consistency.

## Основные входные файлы

- `src/data/experiments/README.md`
- `docs/glossary/project-systems.md`
- `PROJECT_SIGNAL_AUDIT_2026-03-07.md`

При необходимости посмотреть реальные папки:

- `src/data/experiments/`

## Что нужно сделать

1. Проверить фактический список experiment folders в `src/data/experiments/`.
2. Обновить таблицу в `src/data/experiments/README.md` так, чтобы она:
   - ссылалась на реально существующие папки;
   - соответствовала каноническому словарю из S03;
   - не смешивала current/active/archived без пояснения.
3. Если часть записей не должна считаться активными experiments, явно отметить это в таблице:
   - `active`
   - `applied`
   - `analysis only`
   - `historical / intermediate`
4. Если полезно, добавить короткую строку перед таблицей, объясняющую, что индекс ниже — это research index, а не runtime source of truth.

## Что НЕ делать

- не переписывать весь README заново;
- не менять glossary;
- не трогать другие docs без необходимости;
- не архивировать физически папки;
- не делать folder rename.

## Definition of Done

- таблица экспериментов соответствует реальным folder names;
- читатель не уходит в несуществующие пути;
- статусная колонка не конфликтует с новым vocabulary;
- diff остается маленьким и локальным.

## Ожидаемый масштаб

Очень маленькая сессия. В идеале:

- 1 файл изменен;
- без изменений TypeScript-кода.

## Проверка

Достаточно аккуратного diff.

Если случайно затронут код, тогда:

```bash
npm run typecheck
```
